ANUSHA TRADE API END-TO-END GUIDE
Base URL: https://api.anushatrade.com

This guide covers the investor website APIs and admin-panel APIs implemented in this backend.


1. COMMON RULES
---------------

Content types:
- JSON APIs: Content-Type: application/json
- File upload APIs: Content-Type: multipart/form-data

Authentication:
- Public APIs do not need token.
- Protected APIs need JWT access token:

  Authorization: Bearer <ACCESS_TOKEN>

Roles:
- INVESTOR: website/user dashboard APIs.
- ADMIN or SUPER_ADMIN: admin-panel APIs.

Seeded admin users:
- superadmin@anushabazaar.com / Admin@123
- admin@anushabazaar.com / Admin@123

Swagger/OpenAPI:
- https://api.anushatrade.com/swagger-ui.html
- https://api.anushatrade.com/v3/api-docs

Health:
- GET https://api.anushatrade.com/actuator/health

2.9 Mobile OTP login/register with Firebase

This is the recommended app/web flow:

User Opens App/Web
        ↓
Enter Mobile Number
        ↓
Send OTP using Firebase Phone Auth on frontend
        ↓
User Enters OTP
        ↓
Firebase verifies OTP and returns ID token
        ↓
Send Firebase ID token to backend
        ↓
Check User Exists?
      ↙         ↘
   NO             YES
   ↓               ↓
Register         Login
   ↓               ↓
Complete KYC    Open Dashboard

Important:
- Firebase sends the OTP from frontend/app SDK.
- Backend does not receive raw OTP.
- Backend receives Firebase ID token after OTP verification.
- Backend verifies Firebase ID token, extracts verified mobile number, and checks user.

Backend Firebase configuration:
- APP_FIREBASE_PROJECT_ID
- APP_FIREBASE_SERVICE_ACCOUNT_RESOURCE
- APP_FIREBASE_SERVICE_ACCOUNT_PATH
- APP_FIREBASE_SERVICE_ACCOUNT_JSON
- APP_FIREBASE_SERVICE_ACCOUNT_BASE64

Use any one service account method:
- APP_FIREBASE_SERVICE_ACCOUNT_RESOURCE=anushabazaar-2288e-firebase-adminsdk-fbsvc-e520eea937.json
- APP_FIREBASE_SERVICE_ACCOUNT_PATH=C:\keys\firebase-service-account.json
- APP_FIREBASE_SERVICE_ACCOUNT_JSON={...full json...}
- APP_FIREBASE_SERVICE_ACCOUNT_BASE64=base64-of-json

Current backend default:
- app.firebase.project-id=anushabazaar-2288e
- app.firebase.service-account-resource=anushabazaar-2288e-firebase-adminsdk-fbsvc-e520eea937.json

2.9.3 Frontend Firebase OTP example

Install Firebase in frontend:

npm install firebase

Example JavaScript:

import { initializeApp } from "firebase/app";
import {
  getAuth,
  RecaptchaVerifier,
  signInWithPhoneNumber
} from "firebase/auth";

const firebaseConfig = {
  apiKey: "YOUR_FIREBASE_API_KEY",
  authDomain: "YOUR_PROJECT.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  appId: "YOUR_FIREBASE_APP_ID"
};

const app = initializeApp(firebaseConfig);
const auth = getAuth(app);

window.recaptchaVerifier = new RecaptchaVerifier(auth, "recaptcha-container", {
  size: "normal"
});

async function sendOtp(mobileNumber) {
  const appVerifier = window.recaptchaVerifier;
  const phoneNumber = `+91${mobileNumber}`;
  window.confirmationResult = await signInWithPhoneNumber(auth, phoneNumber, appVerifier);
}

async function verifyOtpAndLogin(otp) {
  const credential = await window.confirmationResult.confirm(otp);
  const idToken = await credential.user.getIdToken();

  const response = await fetch("https://api.anushatrade.com/api/auth/firebase-mobile/login", {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({ idToken })
  });

  const result = await response.json();

  if (result.userExists && result.nextStep === "OPEN_DASHBOARD") {
    localStorage.setItem("accessToken", result.accessToken);
    localStorage.setItem("refreshToken", result.refreshToken);
    window.location.href = "/dashboard";
    return;
  }

  if (result.userExists && result.nextStep === "COMPLETE_KYC") {
    localStorage.setItem("accessToken", result.accessToken);
    localStorage.setItem("refreshToken", result.refreshToken);
    window.location.href = "/kyc";
    return;
  }

  if (!result.userExists && result.nextStep === "REGISTER") {
    sessionStorage.setItem("firebaseIdToken", idToken);
    sessionStorage.setItem("verifiedMobileNumber", result.mobileNumber);
    window.location.href = "/register";
  }
}

6. ERROR RESPONSE FORMAT
------------------------

The backend uses consistent API error responses for validation, bad request, forbidden, and server errors.

Common HTTP status codes:
- 200: Success
- 400: Bad request or validation error
- 401: Missing/invalid login token
- 403: Logged in but not allowed, or email not verified
- 404: Record not found
- 500: Server error

Common examples:
- Invalid credentials
- Verify email before login
- Investor must complete KYC and accept mandatory disclosures
- Investment amount is outside plan limits
- Receipt is not approved
- Minimum withdrawal is 1000
- Insufficient wallet balance


7. FRONTEND INTEGRATION NOTES
-----------------------------

Store after login:
- accessToken
- refreshToken
- role
- userId

Route user by role:
- role = INVESTOR: open investor website dashboard.
- role = ADMIN or SUPER_ADMIN: open admin panel dashboard.

Attach token to protected calls:

Authorization: Bearer <ACCESS_TOKEN>

When access token expires:
1. Call POST /api/auth/refresh-token with refreshToken.
2. Replace accessToken.
3. Retry original API.

For file upload APIs:
- Do not send JSON.
- Use FormData in frontend.
- Field names must match exactly.

KYC file field names:
- panCardImage
- aadhaarFrontImage
- aadhaarBackImage
- selfiePhoto
- bankPassbookOrStatement

Receipt upload field names:
- receiptFile
- paymentAmount
- paymentDate
- paymentMode
- bankReference


8. JAVASCRIPT EXAMPLES
----------------------

8.1 Login example

const baseUrl = "https://api.anushatrade.com";

async function login(email, password) {
  const response = await fetch(`${baseUrl}/api/auth/login`, {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({ email, password })
  });

  if (!response.ok) {
    throw new Error(await response.text());
  }

  return response.json();
}

8.3 KYC upload example

async function submitKyc(accessToken, files) {
  const formData = new FormData();
  formData.append("panCardImage", files.panCardImage);
  formData.append("aadhaarFrontImage", files.aadhaarFrontImage);
  formData.append("aadhaarBackImage", files.aadhaarBackImage);
  formData.append("selfiePhoto", files.selfiePhoto);
  formData.append("bankPassbookOrStatement", files.bankPassbookOrStatement);

  const response = await fetch(`${baseUrl}/api/kyc/submit`, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${accessToken}`
    },
    body: formData
  });

  if (!response.ok) {
    throw new Error(await response.text());
  }

  return response.json();
}
