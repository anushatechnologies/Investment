SECTION 1: AUTHENTICATION & ONBOARDING ENDPOINTS
--------------------------------------------------------------------------------

  "password": "Password123",         // Optional (auto-generated if omitted)
  "mpin": "1234",                    // Optional 4 or 6 digit MPIN
  "dateOfBirth": "1995-01-01",       // Optional
  "panNumber": "ABCDE1234F",         // Optional
  "aadhaarLast4": "1234",            // Optional
  "address": "Hyderabad, India",     // Optional

  "bankIfscCode": "SBIN0001234",     // Optional

1.3 UNIVERSAL FLEXIBLE LOGIN (EMAIL OR MOBILE + PASSWORD OR MPIN)
Endpoint: POST /api/auth/login
Headers: Content-Type: application/json

Request Body (JSON):

  "email": "aman@example.com", // OR "mobileNumber": "8019336733"

1.4 SET / UPDATE MPIN
Endpoint: POST /api/auth/set-mpin
Headers:
  Authorization: Bearer <JWT_TOKEN>
  Content-Type: application/json

Request Body (JSON):
{
  "mpin": "1234"
}

Response Body (200 OK):
{
  "message": "MPIN updated successfully"
}

2.2 RECEIPT & WHATSAPP STATUS POLLING (MOBILE APP)
Endpoint: GET /api/receipts/{investmentId}/status
Headers:
  Authorization: Bearer <JWT_TOKEN>

Response Body (200 OK):
{
  "paymentStatus": "SUCCESS",
  "investmentId": "ATINV202608100001",
  "amount": 100000.00,
  "receipt": {
    "receiptNumber": "ATR-2026-000001",
    "receiptUrl": "https://storage.anusha.trade/receipts/ATR-2026-000001.pdf",
    "emailStatus": "SENT",
    "whatsappStatus": "DELIVERED",
    "available": true
  }
}

whatsappStatus Enum Values & UI Handling:
- NOT_SENT  : Dispatch not initiated. (Show default UI)
- QUEUED    : Queued in background worker. (Display: ⏳ Preparing receipt... | Poll every 2-4s)
- SENDING   : Payload sent to Meta API. (Display: ⏳ Sending to WhatsApp... | Keep polling)
- SENT      : Dispatched by Meta to user. (Display: ✓ Sent to WhatsApp)
- DELIVERED : Received on recipient's phone. (Display: ✓✓ Delivered to WhatsApp)
- READ      : Opened by recipient on WhatsApp. (Display: ✓✓ Read on WhatsApp)
- FAILED    : Delivery failed (invalid number / blocked). (Display: ⚠ Delivery failed | Download PDF remains active)
