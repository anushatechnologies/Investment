ANUSHATRADE COMPLETE API GUIDE
Base URL: https://api.anusgatrade.com

NOTE:
- Use this exact base URL only if your deployed domain is "api.anusgatrade.com".
- If your real domain is "api.anushatrade.com", replace the base URL everywhere.

AUTH HEADER FOR PROTECTED APIS:
Authorization: Bearer <accessToken>
Content-Type: application/json

ROLES:
- Public APIs: no token required
- Investor APIs: require INVESTOR accessToken
- Admin APIs: require ADMIN or SUPER_ADMIN accessToken

COMMON LOGIN RESPONSE:
{
  "accessToken": "...",
  "refreshToken": "...",
  "role": "INVESTOR",
  "userId": "..."
}

============================================================

Option A - Email OTP Signup:
1. POST /api/auth/send-otp with email
2. POST /api/auth/verify-otp with email and otp
3. POST /api/auth/register with signupVerificationToken
4. GET /api/auth/verify-email?token=...
5. POST /api/auth/login
6. Upload KYC documents
7. Admin approves KYC
8. POST /api/bank/link
9. POST /api/auth/activate
10. POST /api/auth/set-mpin
